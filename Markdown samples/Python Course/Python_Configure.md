# MODULE 2: CONFIGURE PYTHON INTERPRETER

#### The "interpreter" is the actual Python program that runs your code. You might have more than one Python version installed, so you need to tell VS Code which one to use.

#### Setup

1. **Configure Python Interpreter**
   1. Open the Command Palette ( `Ctrl+Shift+P`) 
   2. Type: `Python: Select Interpreter`
   3. Select the following interpreter: `Python 3.x (C:\Users\YourName\AppData\...)`

> [!NOTE]
>
> If you don't see any options, restart VS Code and try again.
