# BASIC SHORTCUTS

| KEYBOARD KEYS     | ACTION                                            |
| ----------------- | ------------------------------------------------- |
| Ctrl+P            | Quick open a file                                 |
| Ctrl+Shift+P      | Command Palette (do anything)                     |
| Ctrl+` (backtick) | Open terminal                                     |
| Ctrl+S            | Save your file                                    |
| Shift+Alt+F       | Format code neatly (after installing a formatter) |
