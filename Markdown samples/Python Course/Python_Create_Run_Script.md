# MODULE 3: CREATE AND RUN SCRIPT

#### Create a New Script

1. In VS Code, click **File > Open Folder**, and create/select a folder like `python-course`
2. In the **Explorer** tab (left sidebar), click **New File** and name it: `hello.py`
3. In the file, type: **print("Hello, technical writer!")**

#### Run the Script

- Click the green **"Run Python File"** button in the top-right corner, **OR** open the terminal (`View > Terminal` or `Ctrl + ``) 
- Type: **python hello.py**
