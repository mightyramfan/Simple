# KEY AREAS IN VS CODE

| PANEL          | PURPOSE                                            |
| -------------- | -------------------------------------------------- |
| Explorer       | Browse your project files and folders              |
| Editor         | Write and view your Python code                    |
| Terminal       | Run commands like "python myfile.py"               |
| Extensions     | Add new features like Python, Markdown tools, etc. |
| Source Control | Use Git for version control (optional for now)     |
